# 🎙️ Speech to Text

Real-time speech recognition that converts spoken words into text,
supporting multiple languages including Mongolian 🇲🇳.

## ✨ What it does

- 🎤 **Real-time speech recognition** — speak into your mic, text appears instantly
- 🌍 **Multi-language support** — recognizes speech in any language your browser supports
- 🇲🇳 **Mongolian language support** — one of the few web tools that supports Mongolian speech input
- 💻 **No installation needed** — runs entirely in the browser

---

## 🌐 Supported languages

🇲🇳 Mongolian · 🇺🇸 English · 🇯🇵 Japanese · 🇨🇳 Chinese · 🇩🇪 German · 🇫🇷 French · 🇮🇹 Italian · and many more

---

## ⚙️ How it works

```
Browser mic input → Web Speech API → Real-time transcript → Display as text
```

The app uses the browser's built-in **Web Speech API** — no backend,
no external services, fully client-side.

---

## 🚀 Run locally

```bash
git clone https://github.com/Ariuka0/Speech-To-Text
cd Speech-To-Text
# Open index.html in your browser
```
